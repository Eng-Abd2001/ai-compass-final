# دليل تعديل المحتوى (بدون برمجة)

كل نص أو أداة أو صفحة في الموقع موجودة في **ملفات نصية بسيطة** داخل هذا المجلد.
تعدّل الملف، ثم تشغّل أمر الفحص، فيفحص الموقع كل شيء ويخبرك بأي خطأ **بالعربية مع اسم الملف ورقم السطر**.
لا حاجة لفتح أي ملف كود.

## الصيغة (قاعدة واحدة في كل الملفات)

```
اسم_الحقل: القيمة          ← سطر واحد لكل حقل
# هذا تعليق يتجاهله الموقع
---                        ← فاصل بين سجلين (في الملفات التي تحوي عدة سجلات)
```

- لا تغيّر **اسم الحقل** (الكلمة قبل النقطتين)، غيّر القيمة فقط.
- النص له نسختان: `..._en` بالإنجليزية و`..._ar` بالعربية. اكتب الاثنتين دائمًا.
- الرمز `{0}` أو `{1}` داخل نص يعني قيمة يضعها الموقع تلقائيًا (رقم أو اسم): أبقِه في مكانه.
- القيمة في سطر واحد (لا تضغط Enter داخلها).

## ماذا يتحكم فيه كل ملف؟

| الملف أو المجلد | يتحكم في |
|---|---|
| `tools/` | **ملف لكل أداة** (الاسم، الوصف، المنصات، الأسعار، التوثيق). `_TEMPLATE.txt` قالب لأداة جديدة |
| `categories.txt` | تصنيفات الأدوات (فيديو، صور، ...) |
| `platforms.txt` | المنصات (ويب، iOS، ...) وأيها يُحسب «تطبيق للهاتف» |
| `pages/` | **ملف لكل صفحة**: عن الموقع، التواصل، الخصوصية، الشروط، إفصاح الإحالة |
| `ui/home/` | **كل نص ظاهر في الصفحة الرئيسية**، ملف لكل قسم (hero = الواجهة، navigator = الموجّه، tools = الأدوات، ...) |
| `ui/pages.txt` | نصوص صفحات الأدوات (`/en/tools`) والتذييل وصفحة 404 وشريط الموافقة |
| `money.txt` | طرق الربح في «مختبر ربح المال» |
| `future.txt` | عناصر «خريطة المستقبل» |
| `safety.txt` | مواضيع «مركز الأمان» وروابط السياسات الرسمية |
| `careers.txt` | وظائف «رادار الوظائف» |
| `academy.txt` | مستويات الأكاديمية |
| `ads.txt` | **كل الإعلانات** (وكل موضع يشرح أين يظهر) |
| `site.txt` | اسم الموقع ووصفه ولونه وبريد التواصل |
| `VERIFICATION-REPORT.md` | تقرير يُولَّد تلقائيًا: ما تبقى من أدوات لتوثيقها |

## المهام الشائعة

**توثيق أداة** (تحويل «تحتاج تحققًا» إلى «موثّق»):
1. افتح صفحة أسعارها الرسمية (الرابط في `VERIFICATION-REPORT.md`).
2. افتح `tools/اسم-الأداة.txt` واملأ الحقول الأربعة معًا في آخره: `checked` (تاريخ اليوم) و`source` (رابط الصفحة) و`paid_from` وسطر `plan:` لكل خطة. اضبط `free_plan` (yes / no / unknown).
3. شغّل `npm run check`. تتحول علامة الأداة تلقائيًا. إن ملأتَ بعض الحقول فقط يرفض الفحص ويقول لك ما الناقص.

**إضافة أداة:** انسخ `tools/_TEMPLATE.txt` باسم جديد (مثل `my-tool.txt`)، عدّل القيم، شغّل `npm run check`. تظهر الأداة وصفحتها ورابطها في التذييل وخريطة الموقع تلقائيًا.

**حذف أداة:** احذف ملفها ثم `npm run check`.

**تغيير عنوان أو نص في الصفحة الرئيسية:** افتح ملف قسمها في `ui/home/` وابحث عن النص الإنجليزي الحالي (Ctrl+F)، فيجاوره سطر العربي. مثال: عنوان الواجهة في `ui/home/hero.txt` (`h1_en` و`h1_ar`).

**تعديل صفحة (الخصوصية مثلًا):** افتح `pages/privacy.txt`. كل قسم كتلة بعد `---` فيها `heading_en/ar` ثم أزواج `text_en/text_ar` (كل فقرة إنجليزية يقابلها عربية تحتها). أضف قسمًا بنسخ كتلة، واحذفه بحذف الكتلة.
السطر `show_if:` يجعل القسم يظهر فقط حين تكون الإعلانات متوقفة (`ads_off`) أو مفعّلة (`ads_on`)؛ لذلك تتغير صفحتا الخصوصية والإحالة وحدهما عند تفعيل الإعلانات.

**إضافة صفحة جديدة:** انسخ أي ملف من `pages/` باسم جديد (مثل `faq.txt`) وغيّر محتواه. تظهر في الموقع والتذييل وخريطة الموقع.

**إضافة تصنيف أو منصة:** أضف كتلة في `categories.txt` أو `platforms.txt` ثم استخدم اسمها في ملف الأداة.

**الإعلانات:** `ads.txt` (التعليمات في أعلاه). بعد التفعيل يقرأ الموقع كل شيء منه، ويضيف شريط الموافقة، ويحدّث صفحتي الخصوصية والإحالة.

**بريد التواصل:** في `site.txt` (`contact_email`).

## الفحص والتشغيل

| الأمر | وظيفته |
|---|---|
| `npm run check` | يفحص كل الملفات ويكتب التقرير (لا يغيّر شيئًا في الموقع المنشور) |
| `npm run dev` | يشغّل الموقع على جهازك للمعاينة (أعد تشغيله بعد كل تعديل) |
| `npm run build` | يبني الموقع للنشر (يفحص ما سبق أولًا، ويتوقف عند أي خطأ) |

## ما لا يغطيه هذا المجلد

- **أهداف الموقع الستة** (تعلّم، اربح، ابنِ، أتمت، أنشئ، ادرس) ومواضع الإعلانات الثمانية ثابتة في الكود لأن عليها منطق الموقع؛ نصوصها قابلة للتعديل لكن إضافة هدف أو موضع جديد تحتاج مبرمجًا.
- التصميم (الألوان والخطوط) في ملفات الكود وليس هنا.
